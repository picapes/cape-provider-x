# Cape Provider X ([View on Modrinth](https://modrinth.com/mod/cape-provider-x))


<img align="right" src="https://raw.githubusercontent.com/picapes/cape-provider-x/refs/heads/dev/src/main/resources/assets/icon.png" width="192" />

Adds capes to your game!  

Choose from multiple providers or configure your own.  

---

### ✨ About
Cape Provider X is a modified version of the [**Cape Provider** mod](https://github.com/litetex-oss/mcm-cape-provider), maintained by [@xsyanic](https://github.com/xsyanic).  
It contains everything from the original mod, plus additional improvements and integrations.

---

### ⚠️ Compatibility Notice
You **must remove any other cape-related mods** before using Cape Provider X.  
Having multiple cape mods installed at the same time will cause **conflicts and game crashes**.  

---

### 🔧 Changes in This Version
- Tweaks and improvements by **@xsyanic**  
- Added support for [**✨ PiCapes**](https://picapes.github.io)  
- Added support for [SkinMC Capes](https://skinmc.net/capes)
- Added proper support for [Cosmetica Capes](https://cosmetica.cc/) (`-p3` and above)  [Including Animated Cape Support]
- General fixes and stability improvements 
- Cape visible in Offline mode servers too
- Config file renamed to `config/cape-provider-x.json5` *(to avoid conflicts with the original mod’s config)*  
  
---

### 📖 Configuration & Custom Providers
- The [programmatic cape provider](https://github.com/litetex-oss/mcm-cape-provider/tree/dev/PROGRAMMATIC_PROVIDER.md) and `fabric.mod.json` function exactly the same as in the original.  
- For implementing your own provider, see the [custom cape provider guide](https://github.com/litetex-oss/mcm-cape-provider#creating-a-custom-cape-provider).  
- Just note: the config path has changed to: `config/cape-provider-x.json5`
