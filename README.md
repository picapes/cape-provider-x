# Cape Provider X

<img align="right" src="src/main/resources/assets/icon.png" width=192 />

Adds capes to your game!  

Choose from multiple providers or configure your own.  

This is a modified version of the [“Cape Provider” mod](https://github.com/litetex-oss/mcm-cape-provider) done by [xsyanic](https://github.com/xsyanic), with the everything from the orignal mod with following changes:  
* Some Tweaks by @xsyanic
* Added support for PiCapes  
* Added support for SkinMC 
* General fixes and improvements  
* Config is now `config/cape-provider-x.json5` instead of `config/cape-provider.json5` to avoid config conflicts.

The [programmatic cape provider](https://github.com/litetex-oss/mcm-cape-provider/tree/dev/PROGRAMMATIC_PROVIDER.md) and `fabric.mod.json` works the same. Further information/guide is provided in the [custom cape provider implementation](https://github.com/litetex-oss/mcm-cape-provider#creating-a-custom-cape-provider) from orignal repo, but the config would be `config/cape-provider-x.json5` instead. :)
